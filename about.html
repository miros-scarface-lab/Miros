Principles of Computation

I approach software engineering like antique watchmaking: mechanical precision, zero accidental complexity, and utmost respect for machine hardware.

In an era where simple text editors require hundreds of megabytes of memory, I build software that respects cache locality, minimises allocation churn, and achieves predictability.

The Journey So Far

My fascination with computing began when I first opened an x86 disassembly window in GDB. Watching high-level language abstractions melt away into registers, stack pointer offsets, and arithmetic logic flags altered my perception of software permanently.

Since then, I've spent my undergraduate career building systems from first principles: writing a custom 32-bit protected-mode kernel, implementing a statically-typed language compiler with an LALR(1) parser, creating a Raft-consensus distributed store, and sharing this passion with junior peers as a Teaching Assistant.
